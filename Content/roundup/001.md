Hi everyone, Izzy here. Welcome to the first Blazor Roundup.

This first issue is mostly fixes: three problems people are hitting after moving to the .NET 10 SDK, each with a short answer. On the library side, Havit.Blazor ships a breaking change worth a look, and there are two new libraries from the community.

Let's dive in!

## 💸 From Enable Dev Mode

I'm building IzzyBlazor, a component library for Blazor's static server rendering, and this site runs on it. The first alpha is close. The next issue will have the details.

## 📦 Components & libraries

- 📦 [**Havit.Blazor 4.28 - generic HxInputDateRange binds to DateOnlyRange**](https://github.com/havit/Havit.Blazor/releases/tag/v4.28.0) - Breaking if you reference the component type in C#; 4.28.1 removes `HxInputFile.FileCount`.
- 📦 [**MudBlazor.Extensions 9.11 - file viewers for ODF, XPS, DICOM, Parquet and more**](https://github.com/fgilde/MudBlazor.Extensions/releases) - Adds HEIC and PSD image support to its file preview components.
- 📦 [**TimeWarp.State 12.0 betas - moves to .NET 11**](https://github.com/TimeWarpEngineering/timewarp-state/releases) - Several breaking changes: Blazor features split out, an allow-list for actions JavaScript can dispatch, and a new DevTools app.
- 🌱 [**Linq2Dashboard - faceted search over in-memory collections**](https://joadan.github.io/Linq2Dashboard/) - Facets, metric tiles and sliders that feed a grid such as QuickGrid. MIT, beta, from the TabBlazor author.
- 🌱 [**MRX-SDK - map API validation errors onto Blazor form fields**](https://dev.to/remattia/looking-for-feedback-on-a-library-i-built-to-auto-wire-api-validation-errors-to-form-fields-49fl) - Maps Problem Details responses onto `EditContext`, including nested paths like `items[0].name`. The author is asking for feedback.
- ⚠️ [**Material.Blazor v5 deprecated on Nov 10**](https://github.com/Material-Blazor/Material.Blazor) - The README says the v5 line will be deprecated the same day .NET 8 and 9 reach end of support. Plan a move if you're on it.

## 📜 Articles & videos

- 📜 [**Fix: dotnet watch hot reload WebSocket fails on a custom local domain**](https://startdebugging.net/2026/09/fix-dotnet-watch-blazor-hot-reload-websocket-fails-on-custom-local-domain/) - Marius Bughiu - Since the September SDKs, a security fix blocks hot reload from hosts like `myapp.localhost` with no clear error. The fix is one environment variable, set on the watcher process.
- 📜 [**Fix: IAuthenticationService not found with Authorize policies**](https://startdebugging.net/2026/09/fix-unable-to-find-the-required-iauthenticationservice-blazor-authorize-policy/) - Marius Bughiu - Why a protected page works when you click to it but fails on refresh, and three ways to fix it.
- 📜 [**Fix: conflicting assets after upgrading to the .NET 10 SDK**](https://startdebugging.net/2026/09/fix-conflicting-assets-with-the-same-target-path-in-aspnetcore-10/) - Marius Bughiu - If the same file sits in both your server and `.Client` wwwroot folders, the build now fails. Keep each file in one project.
