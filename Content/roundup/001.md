Hi everyone, Izzy here.

.NET 11 hit RC1 this week, and the Blazor changes are mostly polish: Server circuits now pick up a refreshed sign-in without reconnecting, and the browser options API has its final names. September's Patch Tuesday landed the same day, so it's a good week to update.

## 🟦 Blazor

### [.NET 11 Release Candidate 1](https://devblogs.microsoft.com/dotnet/dotnet-11-rc-1/)

RC1 is the first release candidate, and the [ASP.NET Core notes](https://github.com/dotnet/core/blob/main/release-notes/11.0/preview/rc1/aspnetcore.md) have the Blazor details.

* **Auth refresh:** Interactive Server components get the refreshed `ClaimsPrincipal` without a reconnect, so `AuthorizeView` re-renders on its own.
* **Breaking if you tried Preview 7:** the browser options types are renamed (`InteractiveServer`, `StaticServer`, `InteractiveWebAssembly`), and `ValidationOptions.MessageKeyProvider` is gone in favor of built-in resource-key conventions.
* **Fixes:** persisted state survives enhanced navigation, `InputNumber` handles scientific notation, and `Virtualize` and QuickGrid no longer jump or drift.

- 🔐 [**September .NET servicing: 10.0.12, 9.0.20, 8.0.31**](https://devblogs.microsoft.com/dotnet/dotnet-and-dotnet-framework-september-2026-servicing-updates/) - Eight CVEs, including [CVE-2026-69304](https://osv.dev/vulnerability/CVE-2026-69304), an ASP.NET Core denial of service from highly compressed request bodies. Update the runtime and SDK on all three versions.
- 📦 [**Visual Studio 2026 18.10 and 18.9.3**](https://learn.microsoft.com/en-us/visualstudio/releases/2026/release-notes) - 18.10 adds Podman container attach and highlights the operand that decided an `if` while debugging. 18.9.3 is security-only, including two `dotnet watch` fixes.
- 💬 [**.NET Conf 2026 Community Days call for presenters**](https://devblogs.microsoft.com/dotnet/dotnet-conf-2026-community-days-call-for-presenters/) - 30-minute sessions for Nov 12 to 13, with .NET 11 topics preferred. Proposals close Oct 6.

## 📦 Components & libraries

- 📦 [**Blazor.Bootstrap 4.0 - RichTextEditor, FileInput, SplitView, OTPInput**](https://github.com/vikramlearning/blazorbootstrap/releases) - Drops .NET 6 and moves charts into the separate BlazorExpress.ChartJS package, so check both before upgrading.
- 📦 [**BootstrapBlazor 10.10 - Fluent UI theme, async ValidateForm**](https://github.com/dotnetcore/BootstrapBlazor/releases) - 10.10.0 adds the theme and collection validation, and 10.10.1 redesigns async validation with `AsyncValidationAttribute`.
- 📦 [**Radzen Blazor 11.3 - async IQueryable, then reverted**](https://github.com/radzenhq/radzen-blazor/releases) - 11.3.0 ran DataGrid and DropDown queries asynchronously, and 11.3.2 switched back because it caused DbContext conflicts. If you're on 11.3.0 with EF Core, move to 11.3.2.
- 📦 [**Blazorise 2.3.2 - SVG charts over 10x faster on WebAssembly**](https://blazorise.com/blog/release-notes/232) - Large chart datasets drop from a few seconds to a few hundred milliseconds, plus a DatePicker fix for values set after an `await`.
