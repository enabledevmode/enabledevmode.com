## 🟦 Blazor

### [Out-of-band .NET update: 10.0.14, 9.0.22, 8.0.33 and 11 RC3](https://devblogs.microsoft.com/dotnet/dotnet-october-2026-oob-security-updates/)

On Oct 25 Microsoft shipped an unscheduled patch for four CVEs. It re-releases the fix for the Blazor WebAssembly debugger CVE from last issue, because the Oct 13 patch didn't fully close it.

* **CVE-2026-102870:** the [WebAssembly debug proxy](https://github.com/dotnet/aspnetcore/discussions/69791) built C# source from values in the app being debugged without consistent escaping, so attacker-controlled data could run code on your machine when you evaluate an expression. Rated High, CVSS 8.8.
* **Who it affects:** developers debugging Blazor WebAssembly on .NET 10 or 11, not the apps you ship. The 10.0.13 and RC2 packages from Oct 13 aren't enough.
* **Visual Studio:** [18.11.2](https://learn.microsoft.com/en-us/visualstudio/releases/2026/release-notes) carries the fix but lists a known issue: F5 fails to launch the Blazor WebAssembly debug adapter.
* **What to do:** update the SDK and `Microsoft.AspNetCore.Components.WebAssembly.Server` to 10.0.14 (or 11.0.0-rc.3), then restart the debugger and IDE. RC2 users should move to RC3.

- 📜 [**Blazor welcomes open-source contributions from Syncfusion**](https://devblogs.microsoft.com/dotnet/blazor-welcomes-syncfusion/) - Daniel Roth - Syncfusion merged ASP.NET Core fixes (prerendered state on Not Found pages, inherited-model validation, QuickGrid diagnostics), more than 60 end-to-end tests for .NET 11 features, and scaffolding fixes for Blazor Identity pages.

- 🎥 [**Blazor Community Standup: Free Syncfusion Toolkit for Blazor**](https://www.youtube.com/live/1jj1_gZOZYE) - .NET - Daniel Roth and Shriram Sankaran demo the MIT-licensed toolkit's charts, inputs, pickers and dialogs.
