Hi everyone, Izzy here.

October's Patch Tuesday fixes two Blazor CVEs, including a remote code execution, so update your runtime this week. .NET 11 RC2 is out with a go-live license, and .NET 8 and 9 have one regular update left before end of support.

Let's dive in!

## 💸 From Enable Dev Mode

[IzzyBlazor 0.1.0-alpha.2](https://github.com/enabledevmode/izzyblazor/releases) renames `Color` to `Accent` and `Scheme` to `ColorScheme`, and adds what building this site asked for: a dark value for gray, a label slot for the app brand, and videos that aren't out yet.

## 🟦 Blazor

### [October .NET servicing: 10.0.13, 9.0.21, 8.0.32](https://devblogs.microsoft.com/dotnet/dotnet-and-dotnet-framework-october-2026-servicing-updates/)

This month's patches fix 13 ASP.NET Core CVEs, and Visual Studio's advisory names two of them as Blazor: a remote code execution and an elevation of privilege.

* **What to do:** update the runtime and SDK, and rebuild self-contained and container deployments.
* **Which versions:** the remote code execution isn't listed for 8.0.32 or 9.0.21, so it may affect only .NET 10.

- 📦 [**.NET 11 RC2 with a go-live license**](https://devblogs.microsoft.com/dotnet/dotnet-11-rc-2/) - The last release candidate before the Nov 10 launch. For Blazor, QuickGrid's virtualization APIs (`InitialItemIndex`, `ScrollToItemAsync`) are no longer experimental.
- ⚠️ [**.NET 8 and 9 end of support on Nov 10**](https://devblogs.microsoft.com/dotnet/dotnet-8-9-end-of-support/) - October's patches leave one more regular update for 8 and 9. With Blazor CVEs this month, now is a good time to move to .NET 10 LTS (supported to November 2028).

## 📦 Components & libraries

- 📦 [**Radzen Blazor 12.1 - AIChat rebuilt on Microsoft.Extensions.AI**](https://github.com/radzenhq/radzen-blazor/releases/tag/v12.1.0) - Tool calls with approval, citations and attachments, plus new AIPrompt and SmartPasteButton components. AIChat now refuses API keys set in a WebAssembly client, which is the right call.
- 📦 [**Fluent UI Blazor 5.0.1**](https://github.com/microsoft/fluentui-blazor/releases/tag/v5.0.1) - The first round of fixes after the v5 release.
- 📦 [**Blazorise 2.4 - Ribbon, Kbd, Ghost buttons, vertical Steps**](https://blazorise.com/blog/release-notes/240) - Tooltip and ColorPicker no longer need external JavaScript. Reminder: Blazorise needs a paid license for any organization.

## 📜 Articles & videos

- 📜 [**Blazor Basics: Common mistakes beginners make**](https://www.telerik.com/blogs/blazor-basics-common-mistakes-beginners-make-avoid-them) - Claudio Bernasconi - Seven fixes, from loading data in `OnParametersSetAsync` to avoiding `StateHasChanged` loops. Good one to forward to newer teammates.
- 📜 [**Promptless AI-first Blazor apps**](https://www.telerik.com/blogs/promptless-ai-first-blazor-apps) - Héctor Pérez - Build the LLM prompt from ordinary form controls instead of a free-text box, which limits prompt injection. The sample uses Telerik controls, but the pattern works with any library.

## 🔀 .NET & the web

- 📦 [**Visual Studio 2026 18.11 - stop builds on first failure, Hot Exit**](https://learn.microsoft.com/en-us/visualstudio/releases/2026/release-notes) - An opt-in setting ends a solution build at the first error, and unsaved files come back when you reopen.
- 📦 [**Aspire 13.6 - dashboard history, Native AOT dashboard on Fluent UI 5**](https://github.com/microsoft/aspire/releases/tag/v13.6.0) - The dashboard keeps up to ten past runs. Has breaking changes; 13.6.1 fixes dashboard CPU use.
- 📦 [**Playwright 1.64 - WebMCP testing, better videos, locator.within()**](https://github.com/microsoft/playwright/releases/tag/v1.64.0) - Four breaking changes, including elements inside hidden iframes now counting as hidden. Check your Blazor end-to-end tests before upgrading.
- 🌐 [**JPEG XL lands in Chrome 155**](https://developer.chrome.com/blog/jpeg-xl-in-chrome) and [Firefox 158](https://developer.mozilla.org/en-US/docs/Mozilla/Firefox/Releases/158) - Both now decode JPEG XL by default, so you can offer it in a `<picture>` element with a fallback.
