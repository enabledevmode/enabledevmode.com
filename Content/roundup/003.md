Hi everyone, Izzy here.

Microsoft shipped experimental Blazor AI components, a set of building blocks for chat and agent UIs that work with any `IChatClient`. Fluent UI Blazor 5.0 and Radzen 12.0 both landed too, and each has breaking changes worth reading before you upgrade.

## 🟦 Blazor

### [Build agentic UI with the new Blazor AI components](https://devblogs.microsoft.com/dotnet/build-agentic-ui-blazor/)

Daniel Roth introduces `Microsoft.AspNetCore.Components.AI`, an experimental package that needs the .NET 11 SDK.

* **What's in it:** a ready-made `ChatPage`, plus `UIAgent`, `MessageList`, `MessageInput` and `BlockRenderer<TBlock>` for building your own.
* **What it handles:** streamed Markdown, tool calls with human approval, shared state and generative UI.
* **What to do:** try it in a side project. It stays experimental through .NET 11, so expect renames.

- 🎥 [**Blazor Community Standup: Build agentic experiences with the Blazor AI components**](https://www.youtube.com/watch?v=XT6KEenXgEc) - Daniel Roth and Jon Galloway - Demos of tool approval, shared state and generative UI.
- 📦 [**AG-UI protocol gets a first-class .NET SDK**](https://devblogs.microsoft.com/dotnet/ag-ui-dotnet-sdk/) - Daniel Roth - An MIT-licensed SDK built on `IChatClient`, and the protocol the Blazor AI components' interaction model draws on.

## 📦 Components & libraries

- 📦 [**Fluent UI Blazor 5.0 - layout, Card, Toast, DatePicker, Nav and a Theme API**](https://github.com/microsoft/fluentui-blazor/releases/tag/v5.0.0) - A big major with DataGrid hierarchy and pinned columns, a Theme Designer and an MCP docs server. Menu is now Nav, so budget time for the upgrade.
- 📦 [**Radzen Blazor 12.0 - drill-down DatePicker, trimming, Markdown editor**](https://github.com/radzenhq/radzen-blazor/releases/tag/v12.0.0) - DatePicker defaults to drill-down navigation (`NavigationMode=DropDown` brings back the old one), and chart defaults change. Also adds a date range picker and DataGrid export to Excel and CSV in the browser.
- 📦 [**MudBlazor 9.11 - RegexMask presets, fewer re-renders**](https://github.com/MudBlazor/MudBlazor/releases/tag/v9.11.0) - The notes say the median component renders 31% less often than in 9.8.0, and new analyzer hints flag parameters removed since v7.
- 📦 [**Havit.Blazor 4.28 - generic HxInputDateRange**](https://github.com/havit/Havit.Blazor/releases/tag/v4.28.0) - `HxInputDateRange<TValue>` binds to `DateOnlyRange` or `DateTimeRange`, a breaking change. Application Insights no longer needs `'unsafe-eval'` in your CSP.
- 📦 [**ReactiveUI.Blazor 26.0 - trim and AOT-safe WhenActivated**](https://github.com/reactiveui/ReactiveUI/releases/tag/26.0.0) - The second major in a week after 25.0 moved binding to source generators. The .NET 11 build drops runtime async because it failed on Mono, which Blazor WebAssembly uses.
- 🌱 [**MRX-SDK - maps API validation errors onto Blazor WASM form fields**](https://dev.to/remattia/looking-for-feedback-on-a-library-i-built-to-auto-wire-api-validation-errors-to-form-fields-49fl) - Mattia Re - Reads RFC 9457 Problem Details responses and attaches each error to the matching field. Source is on [GitHub](https://github.com/Mattia-Re/MRX-SDK).
