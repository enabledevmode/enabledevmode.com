Hi everyone, Izzy here.

Blazor now has official AI components for building chat and agent UIs. On the library side, Fluent UI Blazor 5 and Radzen 12 both shipped major versions, and both have breaking changes to read about before you upgrade.

Let's dive in!

## 💸 From Enable Dev Mode

[IzzyBlazor 0.1.0-alpha is out](https://github.com/enabledevmode/izzyblazor/releases): my MIT component library for .NET 10, built for static server rendering first. Every component works as plain HTML with JavaScript off and upgrades when scripts run. It ships Dialog, a URL-driven Table, Tabs, Combobox, FileUpload, toasts and theming.

## 🟦 Blazor

### [Build Agentic UI with the new Blazor AI components](https://devblogs.microsoft.com/dotnet/build-agentic-ui-blazor/)

Daniel Roth introduced `Microsoft.AspNetCore.Components.AI`, the first official Blazor components for chat and agent UIs. They wrap any Microsoft.Extensions.AI `IChatClient`, and the package stays experimental for all of .NET 11.

* **Drop-in chat:** `ChatPage` gives you a streaming chat with Markdown out of the box.
* **Build your own:** lower-level pieces (`AgentBoundary`, `MessageList`, `MessageInput`) let you lay out the conversation yourself.
* **Agents that act:** tool calls render as Razor components, and users can approve or reject an action before it runs.
* **What to do:** needs the .NET 11 RC1 SDK or later. Clone the [sample app](https://github.com/danroth27/AgenticUI) in a side project; keep it out of production while it's experimental.

- 📦 [**AG-UI protocol gets a .NET SDK**](https://devblogs.microsoft.com/dotnet/ag-ui-dotnet-sdk/) - Microsoft and CopilotKit released MIT packages for hosting and calling agent endpoints. It's the plumbing the Blazor AI components use to talk to remote agents.

## 📦 Components & libraries

- 📦 [**Fluent UI Blazor 5.0 - new components, hierarchical DataGrid, Theme Designer**](https://github.com/microsoft/fluentui-blazor/releases/tag/v5.0.0) - Microsoft's library hits a stable v5 with a new Theme API, pinned and reorderable DataGrid columns, and a docs MCP server. Breaking: Menu became Navigation and FluentSelect was reworked, so read the migration guide first.
- 📦 [**Radzen Blazor 12.0 - MarkdownEditor, DateRangePicker, client-side Excel export**](https://github.com/radzenhq/radzen-blazor/releases/tag/v12.0.0) - Also adds a VirtualKeyboard, Gantt resource view and Scheduler resource grouping. Breaking: DatePicker drills down by default and chart axes now include zero.
- 📦 [**MudBlazor 9.11 - RegexMask presets, DataGrid SelectionChangeable**](https://github.com/MudBlazor/MudBlazor/releases/tag/v9.11.0) - The release notes claim the median component renders 31% less than in 9.8, plus a long list of DataGrid and DatePicker fixes.
- 📦 [**Ignite UI for Blazor Lite 1.0 - first stable MIT release**](https://github.com/IgniteUI/igniteui-blazor/releases) - Infragistics' free tier is now stable, so breaking changes wait for a major version. No static SSR support yet.
