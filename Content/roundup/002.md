Hi everyone, Izzy here.

It was a quieter fortnight between release candidates, which made room for good deep dives: how C# 15 unions behave in Blazor, and what .NET 11 changes in `Virtualize`. On the library side, Blazor Blueprint shipped two majors and Bit BlazorUI added three new design systems.

## 🟦 Blazor

### [Use C# unions and closed hierarchies in ASP.NET Core](https://devblogs.microsoft.com/dotnet/unions-and-closed-hierarchies-in-aspnetcore/)

Dmitrii Korolev walks through C# 15 `union` types and `closed` classes on .NET 11, including a section on Blazor.

* **What works:** union-typed component parameters, JS interop, `PersistentComponentState` and prerendered parameters.
* **What doesn't:** `[SupplyParameterFromQuery]`, `[SupplyParameterFromForm]` and route values can't bind to unions yet.
* **What to do:** try unions in component parameters on RC1, but keep query-string and form models as plain types.

- 📜 [**Blazor .NET 11: what's new in Virtualize, AnchorMode and CSP support**](https://abp.io/community/articles/blazor-net-11-virtualize-anchormode-csp-performance-hdpestha) - Oğuzhan Ağır, ABP Community - A hands-on RC1 test of variable item heights, scroll anchoring and `ScrollToItemAsync`. Spacers now work under a strict `style-src 'self'` policy, and the default `OverscanCount` goes from 3 to 15.
- 📜 [**Performance improvements in .NET 11**](https://devblogs.microsoft.com/dotnet/performance-improvements-in-net-11/) - Stephen Toub - The yearly tour, headlined by "runtime async", where the runtime rather than the compiler handles `async` methods.
- ⚠️ [**Microsoft's NuGet signing certificate changes Sep 23**](https://devblogs.microsoft.com/dotnet/microsoft-author-signing-certificate-update-2026/) - If your CI uses trusted-signer policies or `dotnet nuget verify`, add the new fingerprint or installs fail with NU3034.

## 📦 Components & libraries

- 📦 [**Blazor Blueprint 4.1 - Gantt, pivot data grid, map chart, QR codes**](https://www.nuget.org/packages/BlazorBlueprint.Components) - The shadcn-style library shipped 4.0 and 4.1 in four days. Several components change behavior, and the Components and Primitives packages must be on matching v4 versions. The author's [nine-month retrospective](https://dev.to/gkg0/blazor-blueprint-nine-months-on-what-ive-learned-from-my-first-open-source-project-2nmn) is a good read too.

- 📦 [**MudBlazor 9.10 - dense DataGrid columns panel, screen-reader work**](https://github.com/MudBlazor/MudBlazor/releases/tag/v9.10.0) - Broad ARIA fixes and fewer unnecessary re-renders, with no breaking changes.
- 📦 [**Havit.Blazor 4.27 - Google Tag Manager on static SSR, CSP nonce**](https://github.com/havit/Havit.Blazor/releases/tag/v4.27.0) - HxGoogleTagManager now works with prerendering and enhanced navigation, and Havit.Blazor.Storage drops a dependency for smaller WebAssembly payloads.
- 📦 [**Radzen Blazor 11.4.2 - synced chart scrollbars, Timeline tracker**](https://github.com/radzenhq/radzen-blazor/releases/tag/v11.4.2) - Also fixes chart sync groups leaking across Blazor Server circuits.
