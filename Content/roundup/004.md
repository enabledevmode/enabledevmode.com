Hi everyone, Izzy here.

October's Patch Tuesday fixes 13 ASP.NET Core CVEs, two of them in Blazor, so update your runtime and SDK this week. .NET 11 RC2 is out with a go-live license, and .NET 8 and 9 reach end of support on Nov 10, the same day .NET 11 launches.

## 🟦 Blazor

### [October .NET servicing: 10.0.13, 9.0.21, 8.0.32](https://devblogs.microsoft.com/dotnet/dotnet-and-dotnet-framework-october-2026-servicing-updates/)

The [10.0.13 release notes](https://github.com/dotnet/core/blob/main/release-notes/10.0/10.0.13/10.0.13.md) list 13 ASP.NET Core CVEs, and [Visual Studio's security table](https://learn.microsoft.com/en-us/visualstudio/releases/2026/release-notes) names two of them as Blazor.

* **CVE-2026-102870:** a remote code execution, listed for .NET 10 only.
* **CVE-2026-96230:** listed for 8.0, 9.0 and 10.0. Visual Studio calls it an elevation of privilege; the .NET release notes call it a remote code execution.
* **Where they are:** advisory databases place both in the WebAssembly debugging tooling (the dev server and debug proxy) rather than in production code paths.
* **What to do:** update the runtime and SDK (10.0.402, 9.0.319 or 8.0.426), and rebuild self-contained and container deployments.

- 📦 [**.NET 11 RC2 with a go-live license**](https://devblogs.microsoft.com/dotnet/dotnet-11-rc-2/) - The last release candidate before the Nov 10 launch. For Blazor, the QuickGrid virtualization APIs `AnchorMode` and `ItemComparer` are no longer experimental, per the [ASP.NET Core notes](https://github.com/dotnet/core/blob/main/release-notes/11.0/preview/rc2/aspnetcore.md).
- ⚠️ [**.NET 8 and 9 end of support on Nov 10**](https://devblogs.microsoft.com/dotnet/dotnet-8-9-end-of-support/) - November's patches are the last for both. .NET 10 is the LTS to move to, supported through November 2028.
- 💬 [**Typed browser platform APIs for Blazor, starting with Web Storage**](https://github.com/dotnet/aspnetcore/issues/69304) - A proposed `Microsoft.AspNetCore.Components.Platform` package lets you call `localStorage` and friends from C# without JS interop. A follow-up [proposal for browser event listeners](https://github.com/dotnet/aspnetcore/issues/69922) sits in the .NET 12 Planning milestone.

## 📦 Components & libraries

- 📦 [**Radzen Blazor 12.1 - AIChat rebuilt on Microsoft.Extensions.AI**](https://github.com/radzenhq/radzen-blazor/releases/tag/v12.1.0) - Tool calls with approval, citations and attachments, plus new AIPrompt and SmartPasteButton components. AIChat now refuses API keys set in a WebAssembly client, so you'll need a server proxy.
- 📦 [**Ignite UI Blazor Lite 1.0 - about 50 free MIT components**](https://www.nuget.org/packages/IgniteUI.Blazor.Lite/1.0.0) - Infragistics' first stable open-source set targets .NET 8 to 10 and needs an interactive render mode. [GridLite](https://www.nuget.org/packages/IgniteUI.Blazor.GridLite/1.0.0) sorts and filters but has no editing or export.
- 📦 [**Syncfusion Toolkit for Blazor 2.0 - unified namespace, theme scopes, CSS isolation**](https://github.com/syncfusion/blazor-toolkit/releases) - Not source-compatible with 1.0.2, and many chart types are now internal. Also fixes static SSR rendering.
- 📦 [**BootstrapBlazor 11.0 - currency input, .NET 11 Virtualize options**](https://github.com/dotnetcore/BootstrapBlazor/releases) - Removes the `--bs-card-body-color` CSS variable, the main thing to check on upgrade.
- 📦 [**Fluent UI Blazor 5.0.1**](https://github.com/microsoft/fluentui-blazor/releases/tag/v5.0.1) - The first round of fixes after v5, with ReadOnly inputs, TimePicker validation and TreeView checkboxes.
- 📦 [**Blazorise 2.4 - Ribbon, Kbd, Ghost buttons, vertical Steps**](https://blazorise.com/blog/release-notes/240) - Tooltip and ColorPicker no longer need external JavaScript. Reminder: Blazorise needs a paid license for any organization.
- 📦 [**Telerik UI for Blazor 15.1 - floating toolbar, Localization Assistant**](https://www.telerik.com/support/whats-new/blazor-ui/release-history/telerik-ui-for-blazor-15-1-0-) - Also hardens HTML sanitization, and Grid CSV export now escapes formula-like values.
- 📦 [**Havit.Blazor 4.29.1 - HxGrid and HxInputFile crash fixes**](https://github.com/havit/Havit.Blazor/releases/tag/v4.29.1) - Fixes an HxGrid timer race that could crash the process, and uploads that hung when disposed mid-transfer.
- 📦 [**bUnit 2.12.5 - DisposeComponentsAsync and stale Find() fixes**](https://github.com/bUnit-dev/bUnit/releases/tag/v2.12.5) - Fixes disposal doing nothing while the dispatcher is busy, and `Find()` returning stale nodes.

## 🔀 .NET & the web

- 📦 [**Visual Studio 2026 18.11 - stop builds on first failure, Hot Exit**](https://learn.microsoft.com/en-us/visualstudio/releases/2026/release-notes) - An opt-in setting ends a solution build at the first error, and another brings unsaved files back when you reopen.

- 🌐 [**Firefox 158 enables JPEG XL by default**](https://developer.mozilla.org/en-US/docs/Mozilla/Firefox/Releases/158) - Chrome 155 [shipped it earlier this month](https://developer.chrome.com/blog/jpeg-xl-in-chrome), so you can offer JPEG XL in a `<picture>` element with a fallback.
